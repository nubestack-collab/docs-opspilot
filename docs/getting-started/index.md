# Getting started

This section takes you from the download page to a working session with an AI answer
in it. You need no account to start: OpsPilot begins a 15-day free trial the first
time it runs, with no email and no activation, and it is a complete terminal from that
first launch. The AI half switches on when you configure a provider or connect an
assistant. After you subscribe, you activate in **Settings → License**.

## The fastest path

If you have ten minutes and a host to log into:

1. [Install](install.md) — download the installer, check it and run it.
2. [First run](first-run.md) — check you are looking at what you expect.
3. [Quickstart](quickstart.md) — first connection to first approved command, about
   five minutes.

## The pages in this section

- **[System requirements](requirements.md)** — minimum and recommended specification,
  which platforms are supported to what degree, the optional licensing connection, and
  what changes if you intend to run a local model so that nothing leaves the
  workstation.
- **[Install](install.md)** — the download page, hash verification, the Windows
  publisher warning, and what does and does not happen during setup.
- **[First run](first-run.md)** — what the window contains before you have configured
  anything, including the trial chip and the AI badges, and what to do first.
- **[Quickstart](quickstart.md)** — numbered steps from install to an approved command:
  create a connection, turn AI on, ask a question, approve the proposal, set your
  safety policy, and subscribe when you are ready.

Which commands may run without asking, and what counts as dangerous, are set per
Command Safety profile. The quickstart's
[safety policy step](quickstart.md) shows where.
