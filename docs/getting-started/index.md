# Getting started

This section takes you from a downloaded installer to a working session with an AI
answer in it. Nothing here requires an account, a tenancy or a licence server, and
OpsPilot is a complete terminal from the first launch — the AI half switches on when
you configure a provider or connect an assistant.

## The fastest path

If you have ten minutes and a host to log into:

1. [Install](install.md) — run the installer for your platform.
2. [First run](first-run.md) — check you are looking at what you expect.
3. [Quickstart](quickstart.md) — first connection to first AI answer, about five
   minutes.

## The pages in this section

- **[System requirements](requirements.md)** — minimum and recommended specification,
  which platforms are supported to what degree, and what changes if you intend to run
  a local model so that nothing leaves the workstation.
- **[Install](install.md)** — per-platform installation, hash verification, and what
  does and does not happen during setup.
- **[First run](first-run.md)** — what the window contains before you have configured
  anything, and what to do first.
- **[Quickstart](quickstart.md)** — five steps: create a connection, work normally,
  choose how the AI reaches you, ask a question, then set your safety policy.

Auto-run and dangerous-command confirmation are set in the quickstart's final step,
[Step 5 — Set your safety policy](quickstart.md).
