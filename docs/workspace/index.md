# Workspace

Once a connection is open, everything happens in one window. The session tab strip runs
across the top, the connections and file explorer panels sit on the left, the terminal is
docked at the bottom of the editor column, and the AI panel is on the right.

This section covers the parts of the window you use after connecting. For getting
connected in the first place, see [Connections](../connections/index.md); for the panel
on the right, see [Using the AI panel](../ai/using-the-ai-panel.md).

- **[The terminal](terminal.md)** — the terminal itself: rendering, search within

- **[Object storage](object-storage.md)** — connecting an S3 or S3-compatible bucket as a
